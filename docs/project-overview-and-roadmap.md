> 整理时间：2026-10-25（阶段 7 授权测试与安装/卸载脚本补齐之后）
> 最近订正：2026-10-31（阶段 9.8 之后；脱敏、LICENSE 署名、CI 与验收数字已同步）
> 代码规模：约 11,000 行 C#（Core 6,000 行 / App 3,000 行 / 测试 2,000 行）
> 公开仓库：https://github.com/Cang-Ruo/DeskLanes

> **名称**：产品与程序集已由 DeskSpace 更名为 **DeskLanes**（中文名「一格桌面」）；
> 仓库目录名仍是 `DeskSpace`（暂未改）。配置目录随之迁到 `%LocalAppData%\DeskLanes\`，

## 一、项目定位与技术栈

Windows 11 本地桌面工作空间管理器：**不改变桌面文件的物理位置**，用虚拟分类 + 自由分区的方式
把桌面项目组织起来，并提供三种随叫随到的界面形态。

| 项目 | 内容 |
|---|---|
| 技术栈 | C# + WPF + .NET 10 LTS（`net10.0-windows`），MVVM（基类手写） |
| 第三方依赖 | **零**。全部 P/Invoke 自实现（热键、托盘、图标、快捷方式解析、已知文件夹） |
| 工程结构 | `DeskLanes.Core`（模型/服务/Win32 互操作）+ `DeskLanes.App`（WPF 界面/应用服务）+ 3 个测试工程 |
| 目标平台 | win-x64，单文件发布，**两个版本**：便携版（framework-dependent）与自包含版（self-contained） |
| 运行时依赖 | 便携版需要 .NET 10 **桌面**运行时（`Microsoft.WindowsDesktop.App` 10.x）；自包含版自带运行时，免安装 |

## 二、功能清单

### 1. 三种界面模式（共用同一份数据，切换不丢任何内容）

| 模式 | 说明 | 主要实现 |
|---|---|---|
| 悬浮窗 | 轻量快速启动窗口，全局快捷键呼出；支持搜索；可设失焦自动隐藏（Esc 也可隐藏） | `Views/FloatingWindow.xaml`、`FloatingWindowViewModel` |
| 全屏工作空间 | 1100×720 主窗口，含**分类导航式**与**自由分区式**两种布局 | `MainWindow.xaml`、`CategoryNavViewModel`、`FreePanelsViewModel` |
| 侧边栏 | 停靠屏幕左侧或右侧的快捷入口栏，可设宽度与失焦自动收起 | `Views/SidebarWindow.xaml`、`SidebarViewModel` |

模式切换入口：设置窗口单选、托盘菜单（悬浮窗/全屏/侧边栏）、`WindowModeManager`。

### 2. 桌面扫描与自动同步

- 扫描**用户桌面 + 公共桌面**（`SHGetKnownFolderPath`，不用会踩坑的逻辑桌面）
- 解析 `.lnk` 快捷方式目标（`ShortcutResolver`），提取多尺寸高清图标（`ShellIcons`，IShellItemImageFactory 256px）
- `FileSystemWatcher` 实时监听两个桌面 → 防抖（400ms / 3s）→ 后台重扫 → UI 线程合并
- 监听失败/目录不可访问时**降级为周期性重扫**，保证最终一致
- 可靠重命名迁移：只有系统明确给出"旧路径→新路径"才迁移关联，不靠文件名或时间猜测
- 失效判定**范围感知**：只对成功枚举的目录内项目判失效，避免"扫不到就被误删"

### 3. 组织能力（虚拟分类，只写 JSON，不改文件位置）

- 分类（分组）：创建、重命名、把项目指派到分类/取消分类
- 自由分区：创建面板、拖拽移动与缩放（ScaleTransform + TranslateTransform）、项目指派到分区、底部"未分区项目池"
- 自定义添加任意文件/文件夹为项目；移除项目
- 项目右键菜单（分类导航与自由分区两种视图都有）
- 全屏模式顶部搜索框实时过滤

### 4. 系统集成

| 功能 | 说明 | 默认 |
|---|---|---|
| 全局快捷键 | `RegisterHotKey` + 消息窗口，只支持组合键（默认 Ctrl+Alt+Space），不注册裸 Win 键、不使用键盘钩子；带"测试"与被占用提示 | 启用 |
| 系统托盘 | 自实现 `Shell_NotifyIcon`（图标、气泡、右键菜单）；菜单项：打开工作空间 / 三种模式 / 设置 / 退出 | 启用 |
| 开机自启 | HKCU Run 启动项，仅当前用户、免管理员 | **关闭**（opt-in） |
| 桌面图标隐藏 | 向 DefView 发 `WM_COMMAND 0x7402`（系统右键菜单同款），保存时再确认一次 | **关闭**（opt-in） |
| 关闭窗口最小化到托盘 | 否则直接退出 | 开启 |

### 5. 设置窗口

窗口模式选择 · 全局快捷键（可测）· 悬浮窗失焦隐藏 · 侧边栏停靠位置/宽度/失焦收起 ·
托盘最小化 · 开机自启 · 桌面图标隐藏 · **卸载前清理**（删自启项 + 恢复图标并同步配置）。

### 6. 配置、日志与安装

- 配置：`%LocalAppData%\DeskLanes\`（`settings.json`、`library.json`），带版本号与宽容加载/迁移；
  旧 `DeskSpace` 目录首次启动时复制迁移
- 日志：同目录 `logs\`（同步日志 + `errors.log`）；单文件下用 `Environment.ProcessPath` 定位（避免 `Assembly.Location` 为空）
- 诊断：设置窗口「导出诊断包」把配置 + 日志 + 备份清单打包成 zip 放到桌面（阶段 8.3）
- 安装/卸载：`tools/install.ps1` / `tools/uninstall.ps1`，每用户、免管理员，已注册到「设置 → 应用 → 已安装的应用」

## 三、数据与存储

```
%LocalAppData%\DeskLanes\
  settings.json    窗口模式/布局/尺寸位置/快捷键/侧边栏/托盘/自启/图标 等
  library.json     项目 Items、分类 Groups、分区 Panels
  logs\            同步与诊断日志、errors.log
```

数据模型带 `Origin`（用户桌面 / 公共桌面 / 自定义），分类与分区都是**虚拟**的——
`library.json` 里只记录"哪个项目属于哪个分类/分区"，磁盘上的文件一个字节都不动。
删除分类/分区只删内部记录，项目仍留在库中。

## 四、安全红线（设计约束，后续开发必须遵守）

1. 不移动、删除、修改桌面上的任何文件
2. 不随意写注册表：只写 HKCU 下三个点（Run 启动项、Uninstall 卸载项、HideIcons 由资源管理器写）
3. 不重启 Explorer（隐藏/恢复桌面图标用切换命令，不是重启）
4. 开机自启、桌面图标隐藏默认关闭，且需要用户逐次授权
5. 不用键盘钩子、不注册裸 Win 键

## 六、已知限制

> 只列**当前仍然成立**的限制；已在阶段 8 / 9 解决的不在此列（解决过程见各阶段文档）。

1. **没有数字签名**：双击 exe 可能触发 SmartScreen「Windows 已保护你的电脑」，需点
   「更多信息 → 仍要运行」。签名不在本阶段范围内。
2. **无自动更新**：升级 = 重新发布 exe 后覆盖安装（`install.ps1` 幂等，可重复执行）。
   这是刻意选择——不做静默自更新，避免破坏"不替用户改本机文件"的安全约定。
   **想装就能用请选自包含版**，可完全绕开运行时依赖。
3. **DPI 与分辨率覆盖不全**：已验证 100% / 125% / 150%（虚拟机与本机混合 DPI、竖屏 720×1280）。
   **未覆盖**：200%+、1366×768 及以下。
   「保存的位置已经不在任何屏幕上」（拔显示器 / 降分辨率后启动）已由端到端 Round H 覆盖；
   仍未覆盖的是**运行中**热插拔与改分辨率。
4. **只在一台真机 + 一台虚拟机上验证过**：真机是 Win11 家庭中文版 Build 26300（125% / 多显示器）；
   虚拟机是专业版 26200（100% / 单屏）。**Win10 兼容未验证**——背景材质是
   **Acrylic 优先、被拒降级 Mica**（两者都属 DWM 系统背景，需要 Windows 11 22621+），
   再退一步的不透明回退分支从未在真机上跑过。
5. **锁屏 / 睡眠恢复未实测**：长时驻留本身已完成（6 小时 / 72 采样，无泄漏，
   见 `docs/stage9-8-soak/report.md`），图标缓存与日志的无界增长也已修掉。
   **仍未验证**：锁屏 / 睡眠唤醒后的窗口与托盘行为（无人值守时脚本不敢锁屏——锁了没人能解锁），
   以及跨天（24h+）级别的驻留。
6. **未验证的场景**：远程桌面会话下的窗口与托盘行为。
7. **中文系统上的缺运行时报错文案未验证**：虚拟机是英文系统，只见过英文报错框。
8. **托盘菜单项文本无法从外部读取**（已知自动化限制，只能靠发送按键 + 观察菜单是否关闭来间接判断）。
9. 若**第三方桌面工具接管了桌面**，可能找不到 DefView，桌面图标隐藏 / 恢复会如实报错（已有处理，不会静默失败）。
10. **Win10 / 200%+ DPI / 1366×768 这些环境仍未覆盖**（见第 3、4 条）。
    ~~`logs\*.log` 只增不减~~ —— 已于 2026-10-30 修复（阶段 9.9 日志轮转），不再作为限制。

### 不建议做（至少现在）

- **改成 MSI / 安装向导**：现有 PowerShell 脚本已覆盖安装、快捷方式、卸载登记，且可读可审计；引入 WiX/Inno 会破坏"零第三方依赖"的约定

- **启用 ReadyToRun 或裁剪**：体积与启动速度的收益不抵反射/COM 互操作的裁剪风险
