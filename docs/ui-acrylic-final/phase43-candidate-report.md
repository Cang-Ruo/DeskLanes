## 一、当前光晕为什么显得太大

阶段 42 光晕层铺满 **76 DIP 渲染窗口**，球只有 44 DIP：
渐变峰值在球边（offset 0.58），但一直衰减到 offset 1.0 = 38 DIP 半径，
**可见直径约 1.7 倍球**，加上三层均匀冷蓝 → 大圈霓虹感。

## 二、候选做法（只改光晕，球体与交互一行没动）

| 项 | 旧（阶段42） | 候选（阶段43） |
|---|---|---|
| 光晕层数 | 3 层（Idle/Hover/Drag 各一） | **1 层** |
| 光晕直径 | 76 DIP（≈1.7×球） | **50 DIP（≈1.14×球）** |
| 光晕形态 | 同心圆均匀发光 | 方向性渐变：左上珍珠白 → 左冰蓝 → 右下淡青蓝，其余透明 |

| Drag 强度 | 31%（偏青） | **17%** |

| 外部描边 | 无 | 无 |
| 渲染窗口 / 命中区 | 76 / 56 DIP | **不变** |

保留：低 Alpha 冰晶主体、珍珠白外轮廓、内折射、局部虹彩、两条波浪、
左上高光、浅色 Tooltip、350ms/6DIP、位置保存、多屏钳制、快捷键。
