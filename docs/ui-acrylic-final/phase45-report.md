# 阶段 45：恢复清晰度（第四轮优化，已合并）

用户指出阶段 44 矫枉过正：光晕收敛了，但球体本身变糊。
核心是**把「球体清晰度」和「外围光晕」分开处理**，本轮重点从「让它发光」转回「让它像一颗漂亮的水晶」。

## 一、问题诊断

阶段 44 的模糊来源：
1. 主体 alpha 太低（中心 9%、中段 14%、边缘 22%）——球体本身没有足够视觉重量；
2. 三条内部光影 + 两条波浪柔光底都带 BlurEffect，叠加后整体糊；
3. 波浪用「两端 alpha=0」的渐变描边，中段才亮——看起来淡；
4. 边缘有 `OrbRimOuter` + `OrbRimInner` + 三条虹彩弧 —— 多重同心圆。

## 二、本轮改动（只改视觉，交互一行没动）

**主体恢复清晰**（不再降低透明度）：中心 21%→**30%**、中段 9%→**14%**、
边缘 22%→**32%**，仍是 ARGB 低 Alpha 玻璃，但一眼能看出球体。

**边缘减到一条主轮廓**：删除 `OrbRimInner`（淡冰蓝内圈）与
`OrbIrisLeft/Right/Bottom`（三条虹彩弧）；只留 `OrbRimOuter`
珍珠白主轮廓 + 左上局部高光弧。没有多个亮度相近的同心圆。

**双轨波浪加锐**：主线改纯色 `#F7FCFF` 2.1 DIP、副线 `#BDE8FF` 2 DIP，
圆头、平行不交叉；删除两层 BlurEffect 柔光底；三态始终全亮（不再随状态变淡）。

**内部丝绸光影压低**：Pearl/Cyan/Lavender 透明度 0.5/0.45/0.48 →
0.32/0.28/0.3，模糊半径 2.5~3 → 2，只提供层次不糊住主体。

**光晕只做辅助**：Idle 1.5% / Hover 12% / Drag 18%（仍是 50 DIP 单层方向渐变），
亮度让位于球体本身。

**Tooltip 不遮挡球体**：`Placement=Bottom` + `VerticalOffset=26`，
文字与延迟不变。实测在球下方、有间距。
