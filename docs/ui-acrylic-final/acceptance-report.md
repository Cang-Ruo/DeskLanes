- 顺带确认：`Full` 模式下 `WindowMaximized=false` 无效（应用自己最大化）。

## 八、基线声明

在下列前提下，把当前轻玻璃主题标记为**设计基线**：

1. 材质：`Desktop Acrylic` 优先 → 被拒退 `Mica` → 再退不透明（`WindowBackdropService`）；
2. 层次：窗口基底 **29%**（阶段 9 由 18% 调整，A/B 见 `phase9-report.md`）/
   导航 30.2% / 内容 20% / 卡片 25.1%，**不再叠加重复层**；
3. 文字（**阶段 14 / 16 / 17 已更新**）：浅色主文字 + 1px 级投影；
   **所有标签（文件名 / 状态栏 / 计数 / 分组标题）统一为 45% 黑半透明底
   `#73000000` + 白字**，能透出壁纸、恒定不随壁纸切换（亮壁纸对比约 4.66:1）。
   阶段 16 的浅灰实心方案已按用户意见撤回；输入框与按钮仍是 45% 深底（`#730A1220`）。
   **固定不随壁纸变化**——阶段 10–13 做的局部亮度自适应已按用户要求默认关闭，
   只有显式 `DESKLANES_DYNAMIC_TEXT=1` 才恢复。阶段 10–13 的像素对比度证据
   描述的是旧默认外观，复现时需带该开关。
4. 四个窗口（主窗 / 悬浮 / 侧边栏 / 设置）共用同一套材质与参数，侧边栏贴边方角。

后续若要改这一层，必须重跑 `tools/phase2-ab.py` 与 `tools/phase3-readability.py`，
否则无法证明"改动没有把玻璃或可读性弄坏"。
