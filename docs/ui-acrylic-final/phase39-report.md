## 二、阶段 2：重建的视觉层（只改 EdgeStripWindow）

球体 44 DIP 可视、56 DIP 热区；**所有材质层被同一 `EllipseGeometry` 裁切**，
球外完全透明（截图里能看到后面的红壁纸和桌面图标，没有矩形底色）。

| 层 | 实现 |
|---|---|
| 1 玻璃主体 | 三态 `RadialGradientBrush`：静止 `#F6FAFF→#CEE6FA→#BCC4F0→#8EA2D8`（opacity 0.74）；悬停 `#FFFFFF→#DDF0FF→#CFD8FA→#9FB4E6`（0.84）；拖动 `#FCFEFF→#D6EDFF→#C6D0F8→#96AAE0`（0.88） |
| 2 内部流动光影 | 三条模糊填充 Path：珍珠白顶部 `#FFFFFF/#DCEEFF`、青绿左下 `#B6F2EC→#8FD8F2→#B7BBF0`、淡紫右下 `#C9B9F2→#E3CFF8→#9FB6E8`，`BlurEffect 2~2.5` |
| 3 虹彩折射 | 一圈 `LinearGradientBrush`（左青绿 `#7FDED8` → 顶白 → 右淡紫 `#C3B2F0` → 底粉 `#E6C9F7`），细描边 1.6 + 模糊柔光 4 |
| 4 两条波浪光带 | 两条**独立 Bezier Path**，都从左下到右上、平行不相交；珍珠白主线 `M6,31 C13,30 16,22 23,21 C30,20 33,13 39,9` 线宽 2.6；浅冰蓝副线 `M5,37 C13,35 17,28 24,27 C31,26 35,19 40,15` 线宽 2.4；各带一层 `BlurEffect 2` 的柔光底（6 / 5.5 宽） |
| 5 高光与折射 | 左上珍珠白弧 `M9,13 A17,17 0 0 1 34,10`；底部粉蓝弧 `#C7B6F2`；内圈 0.7 细反光 |
| 6 环境阴影 | 浅蓝紫 `#6B7DB8` opacity 0.26，`BlurEffect 5`（不再是深蓝实影） |

**三态只改透明度，不改形状**：主体 0.74 / 0.84 / 0.88，光晕 0 / 0.5 / 0.7，
虹彩 0.8 / 0.9 / 0.9，波浪主体 0.92 / 1.0 / 1.0，缩放 1.0 / 1.04 / 1.05（140ms 缓动）。
三条内部光影、两条波浪的路径在三态中**完全相同**，不会跳变。

**Tooltip 同步改浅色冰晶**：背景 `#F0E6F2FF`（94% 浅冰蓝白）、边框 `#B4CDE8`、
文字深蓝灰 `#2A4A6B`、圆角 8、无阴影；550ms 延迟与两种文案不变。
此样式只写在 `EdgeStripWindow.Resources`，不影响其它窗口。
