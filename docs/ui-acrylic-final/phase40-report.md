## 一、先输出的当前（阶段39）真实参数

问题核心：**WPF `#RRGGBB` 默认 100% 不透明**，当前靠元素 `Opacity` 压暗，
是「不透明色 × 元素透明度」双重衰减，叠加后中心几乎不透。

| 层 | 色值 | 色值 Alpha | 元素 Opacity | 有效 Alpha |
|---|---|---|---|---|
| 主体 Idle | `#F6FAFF→#8EA2D8` | **100%** | 0.74 | 74% |
| 主体 Hover | `#FFFFFF→#9FB4E6` | **100%** | 0.84 | 84% |
| 主体 Drag | `#FCFEFF→#96AAE0` | **100%** | 0.88 | 88% |
| 珍珠白光影 | `#FFFFFF→#DCEEFF` | 100% | 0.55 | 55% |
| 青绿光影 | `#B6F2EC→#B7BBF0` | 100% | 0.42 | 42% |
| 淡紫光影 | `#C9B9F2→#9FB6E8` | 100% | 0.5 | 50% |
| 整圈虹彩 | `#7FDED8→#E6C9F7` | 100% | 0.8 + 柔光 0.45 | 80% / 45% |
| 波浪主线 | `#E4F2FF→#FFFFFF` | 100% | 0.92 | 92% |
| 波浪副线 | `#9FD8F5→#BBD8FA` | 100% | 0.88 | 88% |

结论：主体 74% + 三层光影叠加 → 桌面只剩很少透出，中心像「涂了浅蓝漆」；
波浪全长均匀 92% → 像印在表面的 Logo。

## 二、第二版改动（只改 `EdgeStripWindow` 视觉层）

**1. 主体改为色值自带低 Alpha（#AARRGGBB），元素不再压暗：**

| 区域 | Idle | Hover | Drag |
|---|---|---|---|
| 左上高光 | `#35F5FBFF`（21%） | `#42F5FBFF`（26%） | `#4AF5FBFF`（29%） |
| 中心主玻璃 | `#18D9EEFF`（9%） | `#20D9EEFF`（13%） | `#26D9EEFF`（15%） |
| 中下淡蓝折射 | `#269CC8EB`（15%） | `#309CC8EB`（19%） | `#389CC8EB`（22%） |
| 底部淡紫过渡 | `#38B7AFE9`（22%） | `#44B7AFE9`（27%） | `#4CB7AFE9`（30%） |

三态用 `Visibility` 切换三张主体（不再用 Opacity 0/1 动画）。

**2. 玻璃边缘拆三层：**
- 外轮廓：`OrbRimOuter` 细珍珠白 `#DCEEFF` 0.9 DIP，opacity 0.88/0.96/1.0；
- 内折射：`OrbRimInner` 淡冰蓝 `#BDE6FF` 1.2 DIP，Margin 2.2，Blur 1.2，opacity 0.4/0.52/0.62；
- 局部虹彩：三条 `Path`（左下青绿 `OrbIrisLeft`、右侧淡紫 `OrbIrisRight`、
  底部粉蓝 `OrbIrisBottom`），各带渐变 + Blur 2，opacity 0.56~0.9。
  **不再是均匀整圈彩虹。**

**3. 两条波浪升级为流光带：**
- 路径完全沿用阶段39（珍珠白主线 + 冰蓝副线，平行、左下→右上、不相交）；
- 描边改为**两端 Alpha=0、中段高**的 `LinearGradientBrush`
  （主线中段 `#CFFFFFFF`、副线中段 `#A8D8F5FF`），自然淡出；
- 线宽略收细 2.2 / 2.0，柔光底 5 / 4.8、opacity 0.28 / 0.26（Blur 2）。

**4. 内部三片流动光影 alpha 降到 0x18~0x30（约 9~19%），元素 Opacity 0.45~0.56，
只提供层次，不再填满中心。**

**5. 左上高光改局部渐变弧**（两端透明），取代整圈高光。

三态差异来自边缘反射 / 高光 / 光晕，主体保持通透；缩放 1.0/1.04/1.05、
过渡 140ms、Tooltip 550ms 与浅冰晶样式全部保留。
