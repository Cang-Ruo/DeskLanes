# 阶段 2：玻璃透明度与背景层次审查

> 做法：先按**真实视觉树**列出同一像素上到底叠了哪几层，再只改真正重复的那几层。
> 不做"把资源文件里的 alpha 全乘一遍"这种假计算。

---

## 一、复核依据

- 画刷定义：`Themes/GlassTheme.xaml`（α 直接由颜色值算出）
- 叠加关系：逐个窗口读 XAML 的父子结构（`Window.Background` → 根容器 → 面板 → 卡片）
- 只在**同一像素上真正重叠**的层才计入合成；并排的元素不乘

α 换算：`α = 十六进制高两位 / 255`。
有效不透明度按 `1 - Π(1-αᵢ)` 计算（普通 alpha 混合，不是简单相加）。

## 三、结论：三处**同一像素重复叠层**，其余是设计意图

| # | 位置 | 问题 | 判断依据 |
|---|---|---|---|
| 1 | `FreePanelsView` 的 `CanvasBorder` | 画布底色和窗口基底同色同 α，整块 1600×900 画布等于又压了一层 18% | 卡片因此从 38.6% 被抬到 **49.7%**，标题条到 58.8% —— 已经接近半实心，"分区卡片是厚重方块"就是这个原因 |
| 2 | `FloatingWindow` 根 Border | 背景绑定 `Window.Background`，服务已经把同一支画刷设给窗口 → **画两遍** | 实测改前有效 32.8%，几乎是设置窗口（18%）的两倍 |
| 3 | `SidebarWindow` 根 Border | 同上 | 同上 |

**没有改的层（有意保留）**：

- `BrushNavGlass` 30.2% / `BrushPanelGlass` 20.0%：这是"导航比内容深一档"的层次，规格要求保留；
- 搜索框 / 按钮的 7.8% 白：操作控件按规格可以比面板更明显；
- 卡片 25.1%、卡片标题条 18%：属于第三层（卡片），保留层次，只去掉下面重复的那层；
- 菜单 94.9%：弹出层必须保证可读。

## 四、最小改动（3 处，不动布局与交互）

| 文件 | 改动 |
|---|---|
| `Views/FreePanelsView.xaml` | `CanvasBorder` 的 `Background="#2E20334A"` → `Transparent`（交还给窗口基底） |
| `Services/WindowBackdropService.cs` | `Attach/Apply` 增加 `paintWindowSurface` 参数（默认 true）；为 false 时窗口自身背景留空，由带圆角的子 Border 画一次 |
| `Views/FloatingWindow.xaml.cs` | `Attach(this, paintWindowSurface: false)` |
| `Views/SidebarWindow.xaml.cs` | `Attach(this, squareCorner: true, paintWindowSurface: false)` |

改后的层次：

| 区域 | 有效不透明度 |
|---|---|
| 自由分区画布 | 18.0%（= 窗口基底，不再重复） |
| 自由分区卡片 | 38.6%（原 49.7%） |
| 卡片标题条 | 49.6%（原 58.8%） |
| 悬浮窗 / 侧边栏 | 18.0%（原 32.8%） |
| 分类模式导航 / 内容 | 42.8% / 34.4%（不变） |

## 五、前后对照（同一壁纸、同一位置、同一尺寸、活动窗口）

取窗口右中部一块"通常没有控件"的区域算平均亮度。**亮度升高 = 压暗变少 = 更透**。

| 模式 | 改前均值 | 改后均值 | 变化 |
|---|---|---|---|
| 全屏自由分区 | 109.9 | **120.0** | +9.2% |
| 悬浮窗 | 124.2 | **150.5** | **+21.2%** |
| 侧边栏 | 63.9 | **71.9** | +12.5% |

悬浮窗 +21% 正好印证了"画两遍"的判断——去掉一层 18% 就是这么多。
指标已入库（`metrics-before.json` / `metrics-after.json`）。

## 七、遗留风险

1. **悬浮窗圆角**：底色改由带圆角的 Border 画，DWM 自己也有一层圆角（半径可能不同），
   理论上窗口最外圈会出现一圈"没染色的玻璃"。本轮在深色壁纸下**看不出来**，
   但**亮色壁纸下还没验证** —— 建议在阶段 3 的亮壁纸测试里专门看一眼这一圈。
2. **侧边栏收起态**（44 DIP）在新参数下的表现未测（阶段 5）。
3. 本轮只调了"重复层"，**没有改任何单层的 α**。如果还嫌闷，下一步才是动
   `BrushPanelGlass`（20% → 16~18%），但那要配合阶段 3 的可读性数据一起决定。
4. 指标是单次采样，没有做多次取中位数（阶段 4 会做）。
