### 端到端 5 项失败的归因（不是代码回归）

当前 `EnumDisplayDevices` / `EnumDisplayMonitors` 都只返回 **2 台**：

```
DISPLAY2   (0,0,2560,1440)      primary
DISPLAY1   (2560,0,2560,1600)
virtual    (0,0,5120,1600)   SM_CMONITORS=2
```

左侧竖屏 `(-1080,0) 1080×1920` 已不在拓扑里（用户 02:26 拔插后曾手动改回竖屏，
之后系统里又不见了）。失败的 5 条全是 Round D/E/F 的竖屏断言：
拖到另一块屏、跨屏位置持久化、竖屏最大化宽度、还原后留在竖屏、竖屏自动收缩。
**没有竖屏，这些断言的前提就不成立**。阶段 11 已记录过「端到端依赖确定的三屏基线」。

按项目约定**不改判据、不删断言、不标通过**。接回左侧竖屏后重跑
`python tools/verify-floating-interaction.py` 即可恢复 36/36。
同理，`phase13-display-probe.py --target=left` 本轮因找不到左竖屏未跑。
