# 阶段 47：分类选择窗贴着小球走

用户澄清：选择窗不该固定在屏幕某处，要**直接在悬浮球右边展开、跟着小球走**。

## 改动

- `EdgeStripWindow.CurrentBoundsPx`：暴露小球当前窗口矩形（物理像素），
  拖动时实时更新。
- `AppController.OnEdgeStripSingleClick`：不再用写死的 `left=76+6` 和
  屏幕垂直居中，改为按 `CurrentBoundsPx` 算——选择窗左缘 = 球右缘 + 6 DIP，
  垂直中心对齐球中心。
- `OrbPickerWindow.PlaceBesideBall`：按实际高度垂直居中对齐（首次 Loaded 时
  再校正一次；复用窗口时直接用 ActualHeight），避免用估算高度导致偏下。

## 实测

同一进程内长按拖动球从 **(230,230) → (430,350)**（位移 +200,+120），
再单击新位置：

- 选择窗位置 **(513, 201)**，左缘 513 vs 期望 512（**差 1px**）；
- 选择窗垂直中心 389 vs 球中心 388（**差 1px**）。

证明选择窗确实贴着球右缘、跟着球走，并垂直居中。
