# 阶段 23：去掉启动提示、分区避让、底部「全部」区可拖

三件事，均已处理。视觉证据：`phase23-{panels,floating,sidebar}.png`。

## 一、左下角「已启动」

**来源**：`FloatingWindowViewModel` / `SidebarViewModel` 的 `OpenItem()` 成功后会写
`StatusText = "已启动：{name}"`，窗口底部状态栏显示；默认还常驻「就绪」。

**做法**：

- 两个 VM 默认状态文本改为空，`OpenItem` 成功时清空，只有启动失败才写错误提示
- 状态栏加 `Visibility="{Binding HasStatusText}"`，平时整条隐藏

主窗口底部那条状态栏保留：它显示的是「共 N 个项目 / 失效 / 分区 / 扫描时间」与
「自动同步状态」，不是启动提示。若用户想连这条一起去掉，可下一次直接移除。

## 二、创建分区会重叠

**根因**：`WorkspaceService.CreatePanel()` 与 `EnsurePairedContainers()` 补建面板时，
位置都是 `DefaultX/Y + (Panels.Count % 6) * 32` —— 只错开 32px，而面板默认 320×240，
必然互相盖住（用户截图里「游戏」「工具」「编程」就是这样叠在一起）。

**做法**：

- 新增 `FindFreePanelSlot()`：在 1600×900 虚拟画布上按 `320+16 / 240+16` 的网格扫描，
  返回第一个不与任何现有面板矩形相交的位置；画布放满才退回层叠偏移
- `CreatePanel` 与切布局时自动补建面板都改用它
- 工具栏新增「**整理**」按钮（`ArrangePanelsCommand`）：把历史上已经重叠的分区
  按网格重新排一遍，不删任何项目、不动分组归属

冒烟验证：连建 5 个面板两两不相交；人为把两个面板设成同坐标后点「整理」，
重叠消失。

## 三、底部「全部」方框不能往上拖

**根因**：底部区高度是写死的 `ListBox MaxHeight="150"`，没有任何可拖的分隔条。

**做法**：

- `FreePanelsViewModel.PoolPanelHeight`（默认 170，钳在 120–600）
- 底部区顶部加一条 9px 的透明 `Thumb`（细线 + `Cursor=SizeNS` + 提示），
  `DragDelta` 时按 `VerticalChange` 调整高度——往上拖即放大
- `Border` 高度绑定 `PoolPanelHeight`，ListBox 去掉固定 `MaxHeight`、改为按高度滚动
