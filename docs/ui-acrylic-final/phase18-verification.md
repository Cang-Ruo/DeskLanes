## 二、三屏端到端：35 → **36 / 36**

先在**不改任何判据**的前提下直接重跑：从阶段 17 的 29/36 恢复到 **35/36**，
只剩一条 `starts maximized on the portrait monitor -- showCmd=3 at (0,0)`。

这条失败是**阶段 17 的设计变更**，不是缺陷：主窗口改成无边框全屏
（`WindowStyle="None"` + `ResizeMode="NoResize"`）后，用户不再能把主窗口拖到
竖屏，窗口总是最大化在主屏 `(0,0)`；旧断言的前提「能把主窗口放到竖屏」消失了。

处理方式（透明记录，不降低验收强度）：

- **替换**这一条为等价的新设计断言
  `borderless fullscreen: no system chrome and covers the primary monitor`：
  读 `GWL_STYLE`，要求 `WS_CAPTION` 与 `WS_THICKFRAME` 都不存在、窗口处于最大化、
  宽度铺满主屏（≥ 主屏宽 −30 px）。
- 旧断言代码保留在注释里便于回溯；**没有删除任何验收项**，总数仍 36。
- 替换后重跑：**36 / 36，0 失败**。

其余 Round D/E/F 的竖屏断言（拖到另一块屏、跨屏位置持久化、竖屏最大化宽度、
还原后留在竖屏、还原后自动收缩）在左竖屏回来后自然全部通过。
