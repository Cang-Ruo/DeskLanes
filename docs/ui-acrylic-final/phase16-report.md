# 阶段 16：文件名标签改成浅灰

用户看到阶段 14 的深黑名字牌后觉得丑，要求「改成浅灰色」。

## 改动范围

**只改项目文件名标签**（`ItemTile` 的名字牌，三种窗口模式共用）：

| 资源 | 值 | 说明 |
|---|---|---|
| `BrushNamePlate` | `#E6ECECEC` | 约 90% 不透明的中性浅灰，固定不随壁纸变化 |
| `BrushNamePlateText` | `#20242A` | 深灰黑字 |
| `ItemNameTextOnLight` | 基于 `ItemNameText` | 深色字、去掉玻璃投影（投影在浅底上会发脏） |

名字牌不再挂 `dt:DynamicText.Scrim`，保证恒定浅灰。
`BrushLabelScrim`（`#8C000000`，55% 黑）保留给状态栏、分类计数、分组标题等小标签，
本轮**未改动**——见下面「待确认」。

## 可读性

浅底配白字会糊，所以文字同步换成深色：

- 纯浅灰底 `#ECECEC` + 深字 `#20242A` → **13.19:1**
- 叠在最深（黑）壁纸上，90% 不透明度后有效底色约 `#D5D5D5` → **10.62:1**

均远高于 4.5，且因为底色不透明、不随壁纸切换，不会出现阶段 10–13 那种
「有时变白、刷新回不到黑底」的不稳定状态。

## 视觉证据

`phase16-floating.png` / `phase16-category.png`（`UiSnapshot --demo --screen --keep-size`）。
文件名标签统一浅灰底深字；底部「就绪」、顶部分类计数、分组标题仍是深黑底白字。
