# DeskLanes 已知限制

> 面向准备安装与分发 DeskLanes 的人。只列当前仍然成立的限制。

---

## 一、安装与启动

| 限制 | 影响 | 绕开办法 |
|---|---|---|
| **没有数字签名** | 双击 exe 可能弹 SmartScreen「Windows 已保护你的电脑」 | 点「更多信息 → 仍要运行」 |
| **便携版需要目标机预装 .NET 10 桌面运行时**（`Microsoft.WindowsDesktop.App` 10.x），只装 .NET Runtime 不够 | 缺运行时时打不开（会弹 .NET 宿主标准报错框并带下载按钮，不会静默失败） | **选自包含版**，自带运行时，解压即用 |
| 自包含版约 62 MB，比便携版大两个数量级 | 首次传输体积略大 | 首次启动会解压原生运行时到 `%TEMP%`，首启稍慢，属正常行为 |
| **无自动更新** | 新版本需手动替换 | 升级 = 覆盖安装（`install.ps1` 幂等）。刻意不做静默自更新，以免破坏「不替用户改动本机文件」的约定 |
| 只支持 **x64** Windows | ARM64 靠系统模拟可跑但偏慢 | 仅建议验证用 |
| **Win10 兼容性未验证** | 背景材质需要 Windows 11 22621+，Win10 上大概率能跑但视觉效果未知 | 优先 Windows 11 |

## 二、显示与兼容

| 限制 | 说明 |
|---|---|
| **DPI / 分辨率覆盖不全** | 已验证 100% / 125% / 150% 与混合 DPI；未覆盖 200%+、1366×768 及以下。屏幕外坐标（拔屏 / 降分辨率）会自动回到可见区 |
| **只在一台真机 + 一台虚拟机验证** | 真机 Win11 家庭中文版（125% / 多显示器）；虚拟机 Win11 专业版（100% / 单屏 / 无 .NET 运行时） |
| **真实睡眠 / 休眠唤醒未验证** | 锁屏 / 解锁已实测通过；远程会话下 DWM 回退未验证 |
| 侧边栏在极窄 / 极矮屏幕的表现只在 1080p 验证过 | 收起态 44 DIP，展开态 280 DIP |
| **控件可读性优先于透明度** | 输入框与小字带局部底色，保证亮 / 暗壁纸上可读；玻璃质感略有让步 |

## 三、长期运行

- 长时驻留已实测：内存走平、句柄稳定、日志零增长，无泄漏迹象。
- 日志有轮转上限（单份 512 KB + 3 份归档，错误日志 256 KB + 2 份），总量有界。
- 布局切换流畅度已验证：项目较多时切换仍在秒级以内。

## 四、功能边界（设计如此，不是缺陷）

| 限制 | 说明 |
|---|---|
| **不移动、不删除、不修改桌面上的任何文件** | 分类与分区是虚拟归属，只写 JSON |
| 搜索只做**不区分大小写的子串匹配** | 拼音首字母、最近使用排序未实现 |
| 项目右键菜单项较少 | 打开文件所在位置、管理员运行、重命名 / 改分类未实现 |
| 分类与分区**不支持拖拽自定义排序** | 目前用上移 / 下移按钮 |
| **配置只能导出不能导入** | 「导出诊断包」用于排障，不是配置迁移工具 |
| 界面**只有中文** | 尚未抽到资源文件 |
| 第三方桌面工具接管桌面时可能找不到 DefView | 桌面图标隐藏 / 恢复会如实报错，不静默失败 |

## 五、开发侧说明（不影响用户）

- 托盘菜单项文本无法从外部读取，自动化只能间接判断。
- CI（`.github/workflows/build.yml`）只保证构建通过；冒烟测试需要真实桌面环境，不在 CI 运行。
- 单文件 exe 的 MD5 每次编译都可能变（嵌入调试符号），判断产物请用体积与实际运行验证。
- 判断 exe 是否自带运行时，看 `%TEMP%\.net\DeskLanes\<随机目录>\` 下有无 WPF 原生组件（`wpfgfx_cor3.dll` 等），不要用 `coreclr.dll` 判断。
