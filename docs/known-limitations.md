## 一、会影响"能不能装上、能不能打开"

| # | 限制 | 影响 | 绕开办法 |
|---|---|---|---|
| 1 | **没有数字签名** | 双击 exe 可能弹 SmartScreen「Windows 已保护你的电脑」 | 点「更多信息 → 仍要运行」。签名不在本阶段范围内 |
| 2 | **便携版需要目标机预装 .NET 10 桌面运行时**（`Microsoft.WindowsDesktop.App` 10.x）。只装 .NET Runtime 不够，WPF 必须是**桌面**运行时 | 缺运行时时打不开 | **选自包含版**（约 62 MB，自带运行时，什么都不用装）。缺运行时的表现已在干净 Win11 虚拟机实测：弹 .NET 宿主标准报错框并带下载按钮，**不会静默失败**（`docs/stage8-step2.md`） |
| 3 | 自包含版约 62 MB，比便携版大两个数量级 | 传输体积 | 首次启动会把原生运行时解压到 `%TEMP%\.net\DeskLanes\<随机目录>`，首启略慢（.NET 单文件的正常行为） |
| 4 | **无自动更新** | 新版本要手动换 | 升级 = 重新发布 exe 后覆盖安装（`install.ps1` 幂等）。**刻意不做静默自更新**，避免破坏"不替用户改本机文件"的约定 |
| 5 | 只支持 **x64** Windows | ARM64 机器靠系统模拟也能跑，但会明显偏慢 | 仅建议用来验证，不建议当主力 |
| 6 | **Win10 兼容未验证** | 背景材质走 DWM 系统背景（**Desktop Acrylic 优先，被拒则降级 Mica**，两者都不给就回退不透明）；系统背景材质需要 Windows 11 22621+。**不透明回退分支从未在真机上跑过** | Win10 上大概率能跑，但视觉效果未知 |

## 四、功能边界（设计如此，不是缺陷）

| # | 限制 | 说明 |
|---|---|---|
| 13 | **不移动、不删除、不修改桌面上的任何文件** | 分类与分区是虚拟归属，只写 JSON |
| 14 | 搜索只做**不区分大小写的子串匹配** | 拼音首字母匹配、最近使用排序尚未实现 |
| 15 | 项目右键菜单项较少 | 打开文件所在位置、以管理员运行、重命名/改分类尚未实现 |
| 16 | 分类与分区**不支持拖拽自定义排序** | 目前只有上移 / 下移按钮 |
| 17 | **配置只能导出不能导入** | 「导出诊断包」用于排障，不是配置备份/迁移工具 |
| 18 | 界面**只有中文** | 硬编码中文尚未抽到资源文件 |
| 19 | 若**第三方桌面工具接管了桌面**，可能找不到 DefView | 桌面图标隐藏 / 恢复会**如实报错**，不会静默失败 |

## 五、已知的开发侧限制（不影响用户）

| # | 限制 |
|---|---|
| 20 | 托盘菜单项文本无法从外部读取（自动化只能靠发按键 + 观察菜单是否关闭来间接判断） |
| 21 | 冒烟测试是单一控制台程序（约 2900 行，460 项断言），未拆成 xUnit 工程。CI（`.github/workflows/build.yml`）**只保证「构建必须过」**；冒烟在云端跑不了（要真实桌面 + 公共桌面 + 快捷方式 + 文件夹 + 普通文件齐全，runner 上桌面是空的），标了 `continue-on-error`，结果仅供参考 |
| 22 | 单文件 exe 的 MD5 每次编译都会变（嵌入的调试符号重新生成）。判断"产物有没有被改动"请以体积和实际运行验证为准，不要只看 MD5 |
| 23 | 判断某份 exe 是否自带运行时，看 `%TEMP%\.net\DeskLanes\<随机目录>\` 下有没有 **WPF 原生组件**（`wpfgfx_cor3.dll` / `PresentationNative_cor3.dll`）。**不要用 `coreclr.dll` 当判据**——单文件宿主直接从 bundle 加载它，不落盘，拿它判断会误判 |
